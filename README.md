# MA2026_Roboterarm
5-Achsen Sortierroboter mit Bildverarbeitung
Maturaarbeit 2026 von Aleksandar Maric, Ivan Simic und Sayan Hossain.

Anleitung zur Bedienung des technischen Produkts:

1. Produkt auf einer Tischfläche  mit zwei Schraubzwingen befestigen.
2. Würfel auf der Tischfläche verteilen innerhalb eines 40cm Radius von der Drehachse
3. angeschaltetes PeakTech an beiden Kabeln die zu den 6V Servo führen befestigen, sowie das 12V-Netzteil an Strom anschliessen.
4. Schrittmotor auf 0° physisch Einstellen, aus Sicht der Schraubzwingen soll Der Schulterservo links sein und parallel zur Tischkante.
5. Raspberry Pi mit USB-C Netzeil mit Strom versorgen (sofern USB-Kamera und Arduino am Raspberry Pi eingesteckt sind)
   
optional, für bestes Ergebnis: Während des Sortiervorgangs verlorene Schritte manuell zurechtstellen(bei Home-Position wieder auf Home stellen(sofern Schritte verloren))
